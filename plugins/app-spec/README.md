# App Spec

Turns one module of one existing mobile app into a reviewed spec, in a fixed template, with a coverage ledger.
The spec is deep enough to plan and build the same feature in a new app without reading the old code again.

This plugin is under construction. Commands, agents and workflows arrive in later releases.
The contract that every part follows is [docs/DESIGN.md](docs/DESIGN.md).

For install lines, see the [repository README](../../README.md).
